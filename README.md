# Fourshade — site

Páginas públicas da app **Fourshade** para iPhone, servidas pelo GitHub Pages em
<https://fourshadeapp.github.io/>.

| Página | URL |
| --- | --- |
| Suporte | https://fourshadeapp.github.io/ |
| Política de privacidade | https://fourshadeapp.github.io/privacy.html |

As duas páginas estão em inglês, português, espanhol e francês. Abrem na língua do
dispositivo; `#en`, `#pt`, `#es` ou `#fr` no fim do URL escolhem uma língua.

## Publicar

1. Repositório público com o nome `fourshadeapp.github.io` na conta `fourshadeapp`.
2. Carregar `index.html`, `privacy.html` e este `README.md` para a raiz da branch `main`.
3. Settings › Pages › Deploy from a branch › `main` / `(root)`.
